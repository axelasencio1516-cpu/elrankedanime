Política de Privacidad

Última actualización: 19 de septiembre de 2026.

Datos que tratamos

Al crear una cuenta, ElRankedAnime utiliza Firebase Authentication para gestionar tu correo electrónico y sesión. También puede almacenar en Firestore tu perfil público, puntos, racha, inventario, historial de canjes y votos necesarios para las funciones de comunidad.

Conexión con Patreon

Si decides vincular Patreon, la verificación se realiza mediante OAuth y la API de Patreon desde un backend. El sitio conserva únicamente el resultado de la verificación de membresía, la fecha de comprobación y el identificador técnico de miembro necesario para aplicar beneficios. No almacena tus datos de pago ni tu contraseña de Patreon.

Finalidad

Usamos estos datos para prestar las funciones del sitio: autenticar tu cuenta, mantener tus puntos y rachas, evitar votos duplicados, mostrar tu perfil y conceder beneficios de membresía verificados.

Conservación y seguridad

Los datos se conservan mientras la cuenta y las funciones asociadas estén activas. El acceso se limita mediante reglas de Firebase y procesos de servidor para los datos sensibles de membresía.

Tus decisiones

Puedes dejar de vincular Patreon y solicitar actualización o eliminación de los datos de tu perfil mediante los canales oficiales de ElRankedAnime. Algunas funciones pueden dejar de estar disponibles si eliminas datos necesarios para ellas.

Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones del sitio o los servicios utilizados. La fecha de actualización indicará la versión vigente.
